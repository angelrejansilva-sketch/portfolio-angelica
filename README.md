# Portfólio — Angelica Rejan Silva

Site pessoal estático (HTML/CSS/JS puro), pronto para publicar no GitHub Pages.

## Rodar localmente

Basta abrir `index.html` no navegador, ou servir a pasta com qualquer servidor estático.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex.: `portfolio-angelica`).
2. Suba os arquivos desta pasta para o repositório.
3. Em **Settings → Pages**, selecione a branch `main` e a pasta `/root`.
4. O site ficará disponível em `https://<seu-usuario>.github.io/<repo>/`.
